# Candidature stage Alpha to Omega — Léo Arnaud

Site de présentation réalisé pour candidater au stage Web / IA / gouvernance numérique chez Alpha to Omega Consulting (Toulouse).

> Ce README sera complété au fil du projet : choix techniques, outils d'IA utilisés, difficultés rencontrées.

## Objectif

Un site public, rapide et accessible qui présente mon parcours, mes compétences et ma compréhension des missions du stage. Déploiement prévu sur Cloudflare Pages.
